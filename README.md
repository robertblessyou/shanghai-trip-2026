# 上海旅行 PWA 第一版

版本 2026.11.01.3。此資料夾是完整靜態網站，無建置、資料庫或登入需求。內含手機交通卡片、每日行程、圖鑑、住宿與餐廳票券摘要、安裝說明、離線閱讀、更新提示、分享與本機QR Code，另附16:9手繪海報。

## 現在預覽

本機預覽：http://127.0.0.1:8766/pwa/index.html#day1

本機網址只能在這台電腦使用，不能分享給遠端同行者，也不能當成手機正式安裝網址。以file方式雙擊index.html也不會啟用Service Worker。

## 讓同行者使用

1. 將本資料夾內的所有檔案原樣放到一個可對外讀取的HTTPS靜態網站，可部署在網域根目錄或子目錄。
2. index.html、sw.js、manifest.webmanifest、app.js、mobile.css、trip-utils.js、version.json、vendor/、icons/、assets/都需存在且路徑相對關係不變。
3. sw.js以JavaScript內容類型回應，勿設為永不重新驗證的長效快取；HTTPS網站應允許同源Service Worker。無需擴大Service-Worker-Allowed範圍。
4. 用正式網址開啟，等顯示「已可離線閱讀」。按「分享行程」即可複製、開啟系統分享或產生QR Code；同行者無需登入或安裝。
5. iPhone用Safari分享選單加入主畫面；Android用支援瀏覽器的安裝／加入主畫面功能。具體安裝提示因瀏覽器而異。

## 離線與更新

- 首次預快取成功後，HTML內的行程、地圖總覽、地址、費用、圖鑑簡介、必要程式及手繪海報可離線讀取。
- 外部實景照片不保證離線；高德導航和即時資訊仍需連網。
- 開放時間與交通費為規劃資料，離線畫面不能當即時營運資訊。
- 新版需同步調整sw.js的VERSION、index.html內版本與version.json。上傳完整版本後，舊客戶端顯示更新提示，按下更新後切換。
- 完成勾選只存本裝置；不會同步給同行者，也不會替任何人訂位或買票。
- 手機系統可能回收網站儲存空間；旅途中保留海報PNG作為額外備份。

## 已驗證與限制

已驗證：必要檔案和海報12項cache-only檢查、390px手機卡片與展開、日期跳轉、勾選重開保留、版本更新切換、本機分享阻擋、QR獨立解碼、manifest及圖示。

尚未驗證：正式外網網址、實體iPhone／Android安裝、同行者跨裝置開啟。這些須在HTTPS發布後進行。本次沒有部署，也沒有Git寫入。
